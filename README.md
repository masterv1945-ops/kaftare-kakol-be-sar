# کفتر کاکل به سر 🕊️

پیام‌رسان خصوصی فارسی (RTL) برای چند نفر: چت، گروه، فایل، ویس، تماس صوتی/تصویری (گروهی هم)، استوری، اتاق تماشا/شنود، ربات‌ها و کانال اطلاعیه‌ها.

- `index.html` — کل سایت (یک فایل، کم‌حجم‌شده). روی GitHub Pages یا هر هاست ساده کار می‌کند.
- `src/index.src.html` — همان سایت با کد خوانا؛ برای ویرایش از این استفاده کنید و بعد نسخه‌ی کم‌حجم را دوباره بسازید.
- `supabase/functions/` — توابع سرور: `bots` (BotFather)، `bot-api` (Bot API)، `ice-servers` (تماس).
  (تابع `auth-email` — ارسال کد ایمیل — روی Supabase هست و تغییری نکرده جز اینکه ربات‌ها جای کاربران را نمی‌گیرند.)
- `docs/BOT-API.md` — راهنمای ربات‌ساز، `examples/echo_bot.py` — ربات نمونه.

دیتابیس و توابع الان روی پروژه‌ی Supabase `wqdcnnjccvvxeeqhnipe` فعال‌اند؛ برای به‌روزرسانی سایت فقط `index.html` را در مخزن جایگزین کنید.
